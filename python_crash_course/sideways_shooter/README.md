# Sideways Shooter

A Pygame arcade shooter where you pilot a ship, dodge incoming enemies, and fire bullets across the screen.

## Controls

| Input            | Action        |
| ---------------- | ------------- |
| **↑ / ↓**        | Move the ship |
| **Space**        | Fire a bullet |
| **Q**            | Quit the game |
| **Close window** | Quit the game |

## Gameplay

Enemies fly in from the right. Shoot them down before they slip past the left edge of the screen, and avoid colliding with them. The game ends when you run out of lives.
